# 2023 Mono Loco Landing Page

Mono Loco is a website built for a nightclub in Cyprus. The website is designed to provide visitors with easy access to information about the club, events, and promotions. The focus is on speed and performance, utilizing HTML, CSS, and SCSS for a clean, fast, and mobile-friendly design. JavaScript is kept to a minimum to ensure quick loading times and optimal performance for both users and search engines.

For content management, the project uses Nunjucks and Eleventy. Nunjucks helps create reusable templates, while Eleventy is a static site generator that builds fast, static HTML pages from these templates. To manage blog posts, Decap CMS is integrated, allowing the nightclub team to update content easily without needing to modify the code.

The goal of this project is to deliver a smooth and fast user experience while keeping the website simple and easy to maintain for the nightclub team.

## Getting Started

To set up the project locally, follow these steps:

1. Clone the repository:

   git clone https://github.com/HarobMikonam/MonoLoco.git

2. Install dependencies:

   npm install

3. Run the development server:

   npm run start

4. Open the website in your browser by navigating to http://localhost:8080.

## Building the Project

To build the project for production, run:

   npm run build

This will generate static HTML files in the _site directory.

## Content Management

To update content using Decap CMS:

1. Navigate to the CMS dashboard (usually located at /admin).
2. Log in or create an account.
3. Use the CMS interface to add or modify blog posts and other content.
